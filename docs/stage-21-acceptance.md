# 第 21 阶段验收：项目面试题库

## 本阶段交付

- 新增项目面试题库：`docs/interview-qa.md`。
- 覆盖项目介绍、非 CRUD 价值、超卖、Redis Lua、订单状态机、超时取消、幂等、RocketMQ、统一响应、traceId、后台鉴权等问题。
- 每个问题都提供回答思路、参考回答和项目落点。
- 在 `README.md` 和 `docs/learning-map.md` 中补充面试题库入口。

## 为什么要做这一阶段

项目写完以后，面试时最难的不是“我做过”，而是“我讲得清楚”。

面试题库的作用是把项目能力转成可表达的问答：

- 面试官问超卖，你能讲库存扣减和 Redis Lua。
- 面试官问幂等，你能讲支付、验票和消息消费。
- 面试官问 MQ，你能讲异步抢票、延时取消和兜底扫描。
- 面试官问接口治理，你能讲统一响应、traceId 和后台鉴权。

## 自动验收

在项目根目录执行：


预期结果：

- 测试全部通过。
- 新增文档不影响业务代码。

## 手动验收

打开：

```text
docs/interview-qa.md
```

检查以下内容：

- 是否能覆盖项目核心面试问题。
- 是否每个问题都有回答思路。
- 是否每个问题都能落回具体代码或文档。
- 是否有快速背诵版。
- README 和学习地图是否能找到面试题库入口。

## 你需要学会的点

- 面试讲项目不要背文件名，要讲问题、设计、实现和验证。
- 一个好回答要能落到具体项目代码，而不是泛泛讲八股。
- 同一个项目可以拆成多个主题讲：库存、订单、幂等、MQ、接口治理。
- 题库是用来训练表达的，不是用来逐字背诵的。

## 面试表达

可以这样说：

> 我给 EventRush 整理了一份项目面试题库，把超卖、Redis Lua、订单状态机、幂等、RocketMQ 延时消息、traceId 和后台鉴权这些高频问题都整理成了回答思路、参考回答和项目落点。这样我复习时可以直接按面试问题回到对应代码和测试。
