# Stage 56 验收：购票首页内容发布闭环

## 做了什么

- 主办方活动详情新增“首页曝光”，可配置标题、说明、城市、展示时间和顺序。
- 支持上传 JPG、PNG、WebP 图片，单张不超过 5 MB，上传接口受主办方密钥保护。
- 后台提供当前编辑内容的购票首页预览和发布前检查。
- 草稿与线上快照分离：保存修改不会直接替换或下线线上版本，发布后才更新公众页面，并支持紧急下线。
- 购票首页只展示已发布活动在有效时间内的线上内容；多张时轮播，单张时不显示切换控件。

## 你该学会什么

- 内容管理不是“数据库加几个字段”，而是编辑、检查、发布、生效和回滚风险的完整链路。
- 草稿与线上版本必须分开，否则一次普通编辑就可能让公众页面内容消失或提前变化。
- 图片上传要同时处理类型、大小、存储路径、公开访问地址和权限边界。
- 前后台联动要以公开接口为边界，购票端不能读取主办方未发布的编辑稿。

## 怎么验收

1. 启动后端和前端，进入 `/organizer/events/{eventId}`，打开“首页曝光”。
2. 选择一张符合规格的图片，填写文案、城市和有效展示时间，点击“保存草稿”。
3. 打开购票首页 `/`，确认新草稿尚未出现。
4. 回到后台点击“发布到首页”，确认提示发布成功。
5. 刷新购票首页，确认主视觉图片、标题、说明和城市与后台配置一致，点击后进入对应活动详情。
6. 修改标题并再次保存草稿，刷新购票首页，确认仍展示上一版。
7. 再次发布，确认购票首页才切换为新标题。
8. 点击“从首页下线”，确认主视觉立即从购票首页移除，但活动详情仍可访问。
