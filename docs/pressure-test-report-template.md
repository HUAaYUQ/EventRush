可以这样说：

> 我对抢票接口做了本地并发压测，重点不是只看 QPS，而是验证高并发下是否会超卖。压测脚本会统计成功数、失败数、QPS、平均耗时、P95 和 P99。通过对比成功数和票档库存，可以证明没有超卖；通过失败分布可以判断失败主要来自库存不足或重复抢票，而不是系统异常。
